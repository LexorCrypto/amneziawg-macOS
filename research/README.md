## Ключевые выводы (одним взглядом)

- **Baseline:** наш форк — AWG 1.x (`amnezia-wg v0.1.8`, параметры `Jc/Jmin/Jmax/S1/S2/H1–H4`). AWG 2.0 (`S3/S4`, `I1–I5` CPS, динамические `H1–H4`) в клиенте **ещё нет**.
- **Главная слабость AWG 2.0:** маскирует хендшейк + шейпит энтропию, но **не делает поток конформным реальному протоколу** (в отличие от Reality/Hysteria2).
- **ТСПУ 2026** сместился к **поведенческому** детекту (число параллельных соединений, объём данных, ASN) и массово блокирует по **IP/CDN/ASN**, а не только по сигнатуре.
- **Рабочий вектор на апрель 2026:** AWG 2.0 с CPS-мимикрией `I1` под QUIC (полевой кейс на MTS).
- **Приоритет P0:** довести форк до AWG 2.0 + непредсказуемый junk + endpoint/ASN-стратегия. Полнопотоковая QUIC/TLS-маскировка — P1.

> ⚠️ Главный caveat: строгие DPI-факты документированы по **GFW Китая**, не по ТСПУ. Точные механизмы ТСПУ — инференция + полевые отчёты. Прежде чем строить Этапы 2–3, threat-model нужно **проверить эмпирически** на нашей инфраструктуре (VPS-хаб — адрес в `infrastructure.md` / LightRAG `infra/`).

_Метод: многоагентный deep-research воркфлоу — 107 агентов, 25 источников, 116 фактов → 25 верифицировано (23 подтверждено / 2 опровергнуто), голосование 3 независимых агентов._
